# David Steinbroner's Portfolio

The stories behind my product work, from the problem we started with to the decisions that shaped what shipped.

This site brings together product management case studies and independent builds. Some pieces follow a project from start to finish. Others focus on a particular feature or a difficult decision along the way.

[Visit the portfolio](https://davidsteinbroner.com)

## What you'll find

- Case studies about the work and its tradeoffs.
- Shorter write-ups of individual features.
- Personal projects built to explore ideas and solve practical problems.

## Run the site locally

Use the Node.js version in [`.node-version`](.node-version).

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Use `npm run build` to create a static copy in `out/`.

The writing lives in [`content/`](content/). [The project guide](CLAUDE.md) explains the content format, page relationships, and editing conventions.
